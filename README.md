# 项目说明

**概述**：自动化报表合成，利用即时通讯平台，约定的群消息的格式，来批量化生成报表。


有一套完整异常处理机制，异常数据缓存本地，人工在UI界面处理后再重新流入自动生成报表。面对峰值吞吐量，可进入缓冲池，排队缓存本地。细颗粒度的IO
消费锁，保障数据的安全性的同时性能并没有下降很多。
